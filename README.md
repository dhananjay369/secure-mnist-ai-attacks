# Secure MNIST AI Attacks and Defenses

## Project Overview

This project evaluates the security of a Convolutional Neural Network (CNN) trained to classify handwritten digits from the MNIST dataset.

The project follows a red-team and blue-team approach:
- Red Team: Generates adversarial examples and performs label-flipping data poisoning.
- Blue Team: Uses adversarial training to improve model robustness.

The goal is to evaluate both clean-data performance and model behavior under selected security attacks.

## Objectives

- Implement the Fast Gradient Sign Method (FGSM).
- Perform label-flipping data poisoning.
- Train and evaluate a poisoned model.
- Apply adversarial training as a defense.
- Compare baseline and defended models using the same FGSM adversarial samples.

## Experiments

### 1. FGSM Adversarial Attack

FGSM creates adversarial images by applying a small, gradient-based perturbation to the input.

```bash
python -m attacks.fgsm_attack
```

Recorded results:

| Metric | Result |
|---|---:|
| Epsilon | 0.2 |
| Samples evaluated | 5,000 |
| Clean accuracy | 98.26% |
| Adversarial accuracy | 45.12% |
| Prediction change rate | 53.28% |

These results show that the tested model is vulnerable to the selected FGSM perturbation.

### 2. Label-Flipping Data Poisoning

This experiment changes labels for a portion of training examples belonging to digit 7, changing their labels to digit 1.

```bash
python -m attacks.poisoning_attack
python -m attacks.poisoned_train
python -m attacks.evaluate_poisoning
```

Recorded poisoning configuration:

- Source label: 7
- Target label: 1
- Poisoning fraction: 5% of source-class training examples
- Poisoned samples: 313
- Original training set size: 60,000

Recorded evaluation:

| Metric | Baseline | Poisoned model |
|---|---:|---:|
| Clean test accuracy | 98.82% | 98.92% |
| Digit 7 classification accuracy | 98.35% | 99.32% |
| Actual digit 7 predicted as digit 1 | 0 | 2 |

**Interpretation:** The poisoned model retained high clean accuracy. Only two test examples of digit 7 were predicted as digit 1, compared with zero for the baseline. These results do not establish strong targeted poisoning harm in this run.

This experiment uses label flipping; it is not a trigger-based backdoor attack.

### 3. Adversarial Training Defense

Adversarial training exposes the model to adversarial examples during training to improve robustness.

```bash
python -m defense.adversarial_training
python -m attacks.test_defense
```

Recorded comparison using the same FGSM adversarial samples:

| Metric | Baseline | Defended model |
|---|---:|---:|
| Clean test accuracy | 98.82% | 98.25% |
| FGSM adversarial accuracy | 50.23% | 96.51% |

Key findings:

- FGSM adversarial accuracy improved by 46.28 percentage points.
- Clean accuracy decreased by 0.57 percentage points.
- The defense improved robustness against the tested FGSM attack with epsilon 0.2.

These findings apply to the evaluated setup and do not guarantee robustness against every attack.

## Results Files

Experiment outputs are saved in the `results/` directory, including JSON metrics for poisoning evaluation, clean evaluation, FGSM evaluation, and baseline-versus-defense comparison.

## Reproducibility Notes

- Run commands from the repository root.
- MNIST may need to be downloaded on the first run.
- Generated datasets and downloaded MNIST files are excluded from Git.
- Model checkpoints are provided in `models/`.
- Training runs may produce slightly different results depending on the environment and random seeds.
- Re-run the relevant scripts to regenerate experiment outputs.

## Limitations

- The experiments use MNIST, a relatively simple image-classification dataset.
- FGSM evaluation covers a specific perturbation strength.
- The poisoning experiment evaluates label flipping for one source-target label pair.
- Results do not establish robustness against all adversarial attacks or poisoning strategies.
